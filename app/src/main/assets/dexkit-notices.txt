DexKit notices for the Zalo Patch pilot (Zinstant ad-bind resolution only)

This module ships the upstream native Core library UNMODIFIED, dynamically
linked: it is loaded at runtime with System.loadLibrary("dexkit") and never
statically linked into module code. Per the LGPL-3.0 terms that apply to
Core/, the library remains replaceable (it is a standard shared object inside
the module APK), and its complete corresponding source is available from the
upstream repository above.

Pilot scope: DexKit is used only to resolve the two Zinstant advertisement
bind-method names against the installed Zalo base APK, with results cached
locally and gated by structural preflight. It supplies local symbol
descriptors only: no executable code, no feature-setting changes. Existing
feature defaults are unchanged.

Full provenance, fingerprint specification, and verification status are recorded
in the module project's internal development documentation.
